# 跨裝置免代碼「三步查表計分矩陣」 (Zero-Code Lookup Matrix v1.00)

本矩陣專為於任何大語言模型環境（包含瀏覽器、行動裝置、雲端介面）中進行零延遲、免代碼、純文字思維鏈推理計分而設計。無需執行外部 Python 腳本即可精算 CASEL 五大 SEL 素養分數、職場心理韌性與心神負荷指數。

---

## 步驟一：基準分設定與三停比例修正 (Baseline & Three-Division Adjustment)

### 1. 初始基準分 (Initial Baseline)
所有指標之初始基準分數統一設定如下：
- **自我覺察 (Self-Awareness, SA)**：`55`
- **自我管理 (Self-Management, SM)**：`55`
- **社會覺察 (Social Awareness, SO)**：`55`
- **人際關係技巧 (Relationship Skills, RS)**：`55`
- **負責任的決策 (Responsible Decision-Making, DM)**：`55`
- **職場心理韌性 (Workplace Resilience)**：`60`
- **心神負荷指數 (Mental Load Index)**：`45`
*(註：所有分數最終上下限強制約束於 15 至 98 分之間)*

### 2. 三停比例初步修正表 (Three Divisions Correction)

| 三停類型 | 判定特徵描述 | 素養與指數修正值 |
| :--- | :--- | :--- |
| **三停均等型** | 上停、中停、下停比例均衡 (約 1:1:1) | 各項基準分不變，`Resilience +5` |
| **上停飽滿型** | 額頭高廣平正，長度佔比較高 | `SA +5`, `DM +5`, `Mental Load +5` |
| **中停突出型** | 眉眼鼻梁高聳亮麗，中段突出 | `SM +5`, `RS +5`, `Resilience +5` |
| **下停豐厚型** | 地閣圓潤、下巴寬厚飽滿 | `SO +5`, `RS +5`, `Mental Load -5` |
